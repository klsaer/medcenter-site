## 2. Врачи и аккредитация

По **каждому** врачу:

- [ ] ФИО
- [ ] Должность
- [ ] Фото (по желанию) → `assets/img/`
- [ ] Вуз и год окончания
- [ ] Специальность по диплому
- [ ] Ординатура / интернатура + специальность + год
- [ ] Повышение квалификации (тема, организация, год)
- [ ] Стаж
- [ ] **Дата окончания аккредитации** — обязательно
- [ ] Сертификаты (по желанию; аккредитацию не заменяют)

**Как добавить врача:** скопируйте в [index.html](index.html) блок `<article class="dr">…</article>`
целиком и замените данные. Дату аккредитации ставьте **только** в атрибут
`data-until="ГГГГ-ММ-ДД"` — дата на странице и цветной статус
(зелёный / жёлтый / красный) считаются автоматически.

## 3. Прейскурант

- [ ] Полный список услуг: **код по номенклатуре 804н** + наименование + цена в рублях
- [ ] Группировка по классам 063–067 и названия классов
- [ ] Утверждённый прейскурант в PDF
- [ ] Дата начала действия цен
- [ ] Срок оказания платных услуг (по умолчанию — не более 14 рабочих дней, кроме ВМП)

> Цены — за каждую услугу отдельно. Формулировки «от 500 ₽» недопустимы.
> Наименования — строго по номенклатуре, не маркетинговые.

**Как добавить услугу:** строка `<tr>` внутри нужного `<tbody data-class="06X">`.
Поиск по таблице подхватит её автоматически.
