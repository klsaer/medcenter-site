# Что нужно прислать для заполнения сайта

Шаблон свёрстан полностью. Ниже — список данных, которые нужно собрать.
Все места под заполнение помечены в коде атрибутом `data-fill`; на самом сайте
их видно по кнопке **«Показать заглушки»** в верхней плашке.

---

## 0. Общее

| Что | Где на сайте |
|---|---|
| Логотип в кривых (SVG) | шапка, `.brand__mark` |
| Полное наименование организации | шапка, карточка организации, подвал |
| Краткое наименование / вывеска | шапка |
| 1–2 фразы о профиле центра | карточка организации |
| Телефон, e-mail | верхняя панель, контакты, подвал |
| Адрес (юридический и фактический) | блок 1, подвал |
| Ссылка на карту (Яндекс.Карты, конструктор → iframe) | блок 1 |

- [ ] Прямая ссылка на выписку в реестре Росздравнадзора
- [ ] Номер лицензии
- [ ] Дата предоставления лицензии
- [ ] **Полное** наименование лицензирующего органа

- [ ] ОГРН, ИНН, КПП
- [ ] PDF: Устав, свидетельство ОГРН, свидетельство ИНН, выписка ЕГРЮЛ, лицензия с приложением
- [ ] График работы по дням
- [ ] Часы записи на приём
- [ ] Часы и кабинет приёма граждан руководителем
- [ ] Ориентиры проезда, парковка

> QR-код обязателен с 01.09.2025.

## 2. Врачи и аккредитация

По **каждому** врачу:

- [ ] ФИО
- [ ] Должность
- [ ] Фото (по желанию) → `assets/img/`
- [ ] Вуз и год окончания
- [ ] Специальность по диплому
- [ ] Ординатура / интернатура + специальность + год
- [ ] Повышение квалификации (тема, организация, год)
- [ ] Стаж
- [ ] **Дата окончания аккредитации** — обязательно
- [ ] Сертификаты (по желанию; аккредитацию не заменяют)

**Как добавить врача:** скопируйте в [index.html](index.html) блок `<article class="dr">…</article>`
целиком и замените данные. Дату аккредитации ставьте **только** в атрибут
`data-until="ГГГГ-ММ-ДД"` — дата на странице и цветной статус
(зелёный / жёлтый / красный) считаются автоматически.

## 3. Прейскурант

- [ ] Полный список услуг: **код по номенклатуре 804н** + наименование + цена в рублях
- [ ] Группировка по классам 063–067 и названия классов
- [ ] Утверждённый прейскурант в PDF
- [ ] Дата начала действия цен
- [ ] Срок оказания платных услуг (по умолчанию — не более 14 рабочих дней, кроме ВМП)
- [ ] Работаете ли по ОМС; если да — виды помощи + страховые компании

> Цены — за каждую услугу отдельно. Формулировки «от 500 ₽» недопустимы.
> Наименования — строго по номенклатуре, не маркетинговые.

**Как добавить услугу:** строка `<tr>` внутри нужного `<tbody data-class="06X">`.
Поиск по таблице подхватит её автоматически.

## 4. Жалобы и контроль

Для каждого органа — адрес, телефон, сайт, горячая линия:

- [ ] Территориальный орган **Росздравнадзора** по вашему региону
- [ ] Управление **Роспотребнадзора** по вашему региону
- [ ] **Минздрав / департамент здравоохранения** региона
- [ ] **ТФОМС** региона *(если работаете по ОМС)*
- [ ] Страховые медицинские организации *(если работаете по ОМС)*
- [ ] Порядок досудебного обжалования — проверить/поправить 5 шагов под себя
- [ ] Где лежит книга отзывов и предложений
