# Сайт медицинской организации — шаблон

Одностраничный информационный сайт с пятью обязательными блоками:
лицензия и документы, врачи и аккредитация, прейскурант по номенклатуре 804н,
контакты для жалоб, правовая информация.

Без сборщиков, фреймворков и зависимостей — чистые HTML, CSS и JS.

---

## Запуск

```bash
node server.js          # http://localhost:3000
node server.js 8080     # другой порт
```

Сервер печатает и адрес в локальной сети — по нему сайт открывается
с телефона, если он в той же Wi-Fi сети.

Питон вместо ноды, если удобнее:

```bash
python -m http.server 3000
```

## Сайт онлайн

**https://klsaer.github.io/medcenter-site/**

Хостится на GitHub Pages из ветки `main`, папка — корень репозитория.
Обновление сайта = обычный пуш:

```bash
git add -A
git commit -m "что поменяли"
git push
```

Пересборка занимает около минуты. Статус — во вкладке Actions репозитория
или командой `gh api repos/klsaer/medcenter-site/pages/builds/latest --jq .status`.

Файл `.nojekyll` в корне отключает обработку через Jekyll — статика отдаётся как есть.
Папка `dist/` в `.gitignore`: она генерируется локально и на хостинге не нужна.

## Как ещё отправить на проверку

**Одним файлом.** Собрать всё (стили, скрипты, картинки) в один HTML:

```bash
node build.js
```

Получится `dist/index.html` — самодостаточный файл. Его можно отправить
в мессенджере или почтой: открывается двойным кликом, интернет не нужен.

**Ссылкой.** Залить содержимое папки на любой статический хостинг —
подойдёт что угодно: Netlify Drop, Vercel, GitHub Pages, Timeweb, reg.ru.
Сборка не нужна, заливаются файлы как есть.

## Заполнение

Весь текст лежит в [index.html](index.html) — правится прямо там,
никакой отдельной админки или конфига.

Места под заполнение помечены атрибутом `data-fill`. На сайте есть кнопка
**«Показать заглушки»** — подсвечивает всё незаполненное и показывает счётчик.
Когда счётчик дойдёт до нуля, сайт готов.

Подробный список данных — в [CONTENT.md](CONTENT.md).

### Что считается автоматически

| Что | Откуда берётся |
|---|---|
| Дата и статус аккредитации врача | атрибут `data-until="ГГГГ-ММ-ДД"` у блока `.accr` |
| Строка «Сегодня» в верхней панели | массив `SCHEDULE` в начале [main.js](assets/js/main.js) |
| Счётчик услуг в прейскуранте | число строк в таблице |
| Год в подвале | текущая дата |

Статус аккредитации: зелёный — действует, жёлтый — осталось меньше 180 дней
(порог `ACCR_WARN_DAYS`), красный — истекла.

## Оформление

**Основная тема — светлая.** Она задана в `:root` в начале
[styles.css](assets/css/styles.css) и системной настройкой телефона или
компьютера не отменяется: сайт всегда открывается светлым.

Тёмная — дополнительная, включается только кнопкой в шапке, выбор запоминается.
Её палитра лежит в блоке `:root[data-theme="dark"]` там же.

Все цвета — CSS-переменные, меняете переменную — меняется вся страница.

Если тёмная тема не нужна совсем: удалить блок `:root[data-theme="dark"]`
из CSS и кнопку `#themeBtn` из [index.html](index.html).

Шрифты системные: кириллица везде отрисуется правильно, грузить ничего не нужно.
Моноширинным набраны все регламентные идентификаторы — номер лицензии, ОГРН, ИНН,
коды 804н, даты, цены.

Проверено на ширинах 360, 390, 780 и 1440 px; горизонтального скролла нет.
Есть стили для печати — страница нормально уходит в PDF.
